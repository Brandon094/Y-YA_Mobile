# Ficha Técnica - YÁYA

## Información General
- **Nombre del Proyecto:** YÁYA
- **Versión Actual:** 0.1.0
- **Desarrollador:** BH++
- **Estado:** En Desarrollo (Alpha)
- **Plataforma:** Android

## Especificaciones de Software
- **Min SDK:** 24 (Android 7.0 Nougat)
- **Target SDK:** 34 (Android 14)
- **Lenguaje:** Kotlin
- **Base de Datos:** PostgreSQL (vía Supabase)
- **Autenticación:** Supabase Auth (Email, Google)

## Funcionalidades Clave
1. Registro y Perfil de Usuario (Cliente/Prestador).
2. Buscador de servicios por categoría.
3. Sistema de reservas y confirmación.
4. Chat en tiempo real (Planificado).
5. Pasarela de pagos (Planificado).
