# 🔵 ISO/IEC 12207
### Ciclo de Vida del Software (SDLC)

**"No es solo programar, es orquestar un proceso"**

- **🎯 Objetivo:** Estandarizar las etapas desde la concepción hasta el retiro del software.
- **🛠️ Estructura de Procesos:**
  - **Principales:** Adquisición, Suministro, Desarrollo, Operación.
  - **De Apoyo:** Gestión de Configuración (Git), Aseguramiento de Calidad (QA).
  - **Organizacionales:** Gestión de Proyectos y Mejora Continua.

**💡 Impacto Real:** Previene el caos técnico, permite estimaciones reales de costos y asegura que el código sea <span class="highlight">escalable</span>.

# 🔴 ISO/IEC 27001
### Seguridad de la Información (SGSI)

**"Protegiendo el activo más valioso: Los Datos"**

- **🎯 Objetivo:** Implementar un Sistema de Gestión de Seguridad para mitigar riesgos.
- **🛡️ La Tríada de la Seguridad (CIA):**
  - **Confidencialidad:** Acceso solo a personal autorizado.
  - **Integridad:** Datos exactos, sin alteraciones no autorizadas.
  - **Disponibilidad:** El sistema responde cuando se le necesita.

**🔒 Beneficio:** Cumplimiento legal (Habeas Data), blindaje contra ciberataques y generación de <span class="highlight">confianza digital</span>.
