# 🟢 ISO/IEC 25010: Calidad del Producto
### "La vara de medir del software"

**1. Objetivo:** Definir un modelo sistemático para evaluar la calidad de un producto de software terminado.
**2. Pilares (8 Características):**
- Adecuación Funcional | Eficiencia de Desempeño | Usabilidad | Fiabilidad | Seguridad | Compatibilidad | Mantenibilidad | Portabilidad.
**3. Impacto:** Garantiza que el producto final cumpla con las expectativas del usuario y sea técnicamente robusto.
**4. Ejemplo:** Una App bancaria que no se cierra (Fiabilidad) y es fácil de usar (Usabilidad).

---

# 🔵 ISO/IEC 12207: Ciclo de Vida del Software
### "El mapa del proceso"

**1. Objetivo:** Establecer una estructura común para los procesos de vida del software, desde la concepción hasta el retiro.
**2. Componentes Principales:**
- **Procesos Principales:** Desarrollo, Operación y Mantenimiento.
- **Procesos de Apoyo:** Documentación, QA y Gestión de Configuración.
- **Procesos Organizacionales:** Gestión y Mejora.
**3. Impacto:** Reduce la incertidumbre, previene el caos en el equipo y permite estimar tiempos y costos reales.
**4. Ejemplo:** El uso de Git y metodologías Ágiles para documentar cada cambio en el código.

---

# 🔴 ISO/IEC 27001: Seguridad de la Info.
### "El blindaje de los activos"

**1. Objetivo:** Proporcionar un modelo para establecer, implementar y mejorar un SGSI (Sistema de Gestión de Seguridad de la Información).
**2. Pilares (Tríada de la Seguridad):**
- **Confidencialidad:** Solo autorizados acceden.
- **Integridad:** La información no se altera sin permiso.
- **Disponibilidad:** El sistema funciona cuando se necesita.
**3. Impacto:** Protege contra ciberataques, evita fugas de datos sensibles y cumple con marcos legales (Habeas Data).
**4. Ejemplo:** El uso de cifrado SSL y autenticación de dos factores (2FA).

---

# ⚖️ ¿Cómo se integran las tres?

- **ISO 12207:** Nos dice **CÓMO** trabajar ordenadamente.
- **ISO 25010:** Nos dice **QUÉ** características debe tener el resultado para ser de calidad.
- **ISO 27001:** Nos dice cómo **PROTEGER** todo lo anterior y los datos de nuestros usuarios.
