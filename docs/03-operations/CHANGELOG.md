## [0.1.0] - 2025-03-05
### Añadido
- Arquitectura base MVVM con Jetpack Compose y Kotlin 2.2.10.
- Navegación Type-Safe para todas las pantallas principales.
- Integración completa con Supabase (Auth, Postgrest, Realtime).
- Persistencia de sesión automática con SharedPreferences.
- Flujos de negocio: Home, Contratación, Confirmación, Perfil, Mis Pedidos, Mis Servicios.
- Dashboard para Prestadores con gestión de solicitudes entrantes.
- Centro de Documentación técnica y de negocio organizado en `/docs`.
