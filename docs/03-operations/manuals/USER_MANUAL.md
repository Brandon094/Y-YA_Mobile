# Manual del Usuario - YÁYA

Este manual proporciona instrucciones detalladas sobre cómo utilizar la plataforma YÁYA desde la perspectiva del Cliente y del Prestador.

## 1. Para Clientes (Solicitantes de Servicio)
### 1.1. Registro e Inicio de Sesión
- Descargue la aplicación y seleccione "Regístrate".
- Elija el rol "Quiero servicios".
- Complete su perfil con datos reales para generar confianza con los prestadores.

### 1.2. Búsqueda de Servicios
- Use la barra de búsqueda en el Home para encontrar servicios específicos.
- Filtre por categorías (Limpieza, Mascotas, etc.) usando los chips superiores.
- Haga clic en una tarjeta de servicio para ver el detalle, precio y reputación del prestador.

### 1.3. Proceso de Contratación y Negociación
- Dentro del detalle del servicio, presione "Solicitar este servicio".
- Defina la fecha, hora y dirección.
- Envíe una oferta inicial.
- **Negociación:** Si el prestador envía una contraoferta, podrá aceptarla o proponer un nuevo valor desde "Mis Pedidos".
- **Handshake Digital:** Una vez lleguen a un acuerdo de precio (estado: Aceptada), usted como cliente debe pulsar **"Confirmar y Empezar"** para blindar el trato e iniciar oficialmente el trabajo.

### 1.4. Chat y Reputación
- Use el chat integrado para coordinar detalles finales con el prestador.
- Tras finalizar el servicio, califique con estrellas y deje un comentario para ayudar a la comunidad.

## 2. Para Prestadores (Talentos Independientes)
### 2.1. Creación de Perfil Profesional
- Regístrese con el rol "Ofrecer talentos".
- Es obligatorio completar el Documento de Identidad y dirección para poder publicar.

### 2.2. Publicación de Servicios
- Use el botón "+" en el Home o vaya a "Mi Perfil" > "Mis Servicios".
- Defina un título claro, descripción detallada y precio base.
- Especifique si incluye materiales o si tienen un costo extra.

### 2.3. Gestión de Solicitudes
- Recibirá notificaciones en el icono de la campana.
- Puede **Aceptar**, **Rechazar** o enviar una **Contraoferta** si el precio o fecha propuestos no le convienen.
