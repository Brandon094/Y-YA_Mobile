# Manual del Administrador - YÁYA

Este manual detalla las funciones de supervisión y gestión del ecosistema YÁYA a través del Dashboard Administrativo.

## 1. Gestión de Usuarios
- **Moderación de Perfiles:** Capacidad de suspender cuentas que infrinjan los términos de uso.
- **Validación de Identidad:** Verificación de documentos cargados por prestadores para otorgar el distintivo de "Verificado".

## 2. Supervisión de Contenidos (Calidad)
- **Auditoría de Servicios:** Revisión de publicaciones para evitar "servicios basura", falsos o ilegales.
- **Gestión de Categorías:** Crear, editar o eliminar categorías del catálogo principal.

## 3. Reportes y Moderación Progresiva
- **Semáforo de Severidad:** El panel de reportes agrupa denuncias por usuario.
    - 🟡 **1-2 Reportes:** Llamado de atención recomendado.
    - 🟠 **3-4 Reportes:** Suspensión recomendada (Desactivación de servicios).
    - 🔴 **5+ Reportes:** Eliminación de cuenta recomendada.
- **Acciones Directas:** 
    - **Llamado de Atención:** Envía un mensaje automático explicativo al infractor vía chat.
    - **Suspender:** Desactiva todos los servicios del infractor.
    - **Eliminar:** Borra la cuenta permanentemente.

## 4. Privacidad y Seguridad del Moderador
Para proteger la integridad de los administradores (Mauro, Harold, Brandon), el sistema implementa una **Capa de Anonimato Automático**:
- **Enmascaramiento de Identidad:** Cuando un administrador interactúa con un usuario común, el nombre se reemplaza por "Equipo de Moderación" y el avatar por el logo oficial de YÁYA.
- **Comunicación Interna:** La identidad real solo es visible entre administradores.
- **Notificaciones Blindadas:** Las alertas push enviadas por administradores no revelan nombres personales.

## 5. Resolución de Conflictos
- Intervención en disputas entre Clientes y Prestadores sobre pagos o calidad del servicio.
