02. Arquitectura de Software

YÁYA implementa un patrón Clean MVVM acoplado a un sistema de Diseño Atómico, garantizando que cada línea de código sea escalable y mantenible.

Componente Atómico

"Las vistas son 100% pasivas. Toda lógica de negocio y transformación de datos reside exclusivamente en los ViewModels mediante UiState."

03. Modelo Relacional

Esquema PostgreSQL optimizado para el ecosistema multi-rol:

profiles Auth Identity & Metadata
services Talent Catalog & Availability
requests Handshake Transaction Flow
messages Realtime P2P Chat

04. Seguridad y RLS

Blindaje a Nivel de Fila (Row Level Security)

Ninguna consulta al servidor es anónima. PostgreSQL valida el JWT de Supabase para asegurar que un usuario solo pueda leer o editar datos que le pertenecen o sobre los que tiene permisos de negociación.

Bank-Level Security

05. Edge Functions & FCM
