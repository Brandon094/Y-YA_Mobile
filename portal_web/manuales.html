Manual del Usuario

1. Para Clientes (Solicitantes)

1.1. Registro: Descargue la aplicación, seleccione "Regístrate" y elija el rol "Quiero servicios".

1.2. Búsqueda: Use la barra de búsqueda o filtros por categoría (Hogar, Mascotas, etc.) para encontrar al experto ideal.

1.3. Contratación y Handshake: Defina fecha y dirección. Al llegar a un acuerdo de precio, pulse "Confirmar y Empezar" para blindar el trato.

2. Para Prestadores (Talentos)

2.1. Perfil Profesional: Registre su documento de identidad y dirección para habilitar la publicación de servicios.

2.2. Publicación: Defina títulos claros, fotos reales de su portafolio y precios base competitivos.

2.3. Negociación: Gestione solicitudes entrantes, acepte o envíe contraofertas en tiempo real.

Manual del Administrador

Moderación Progresiva

Use el semáforo de severidad para gestionar reportes. Envíe "Llamados de Atención" preventivos antes de suspender o eliminar cuentas.

Anonimato de Moderación

El sistema enmascara su identidad real como "Equipo de Moderación" para proteger su privacidad ante los usuarios.
